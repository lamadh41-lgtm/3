# ProSpace — مساحتك الاحترافية

واجهة ويب فاخرة مستوحاة بشدة من تصميم **PlayStation 5**.

تجربة داكنة سينمائية مع كروت أشبه ببلاطات الألعاب، توهج أزرق التركيز، وأنيميشن ناعم جداً.

## المميزات

- قوائم مخصصة (ألعاب، شغل، مذاكرة، ميديا...) + إضافة قوائم جديدة
- رفع أي نوع ملفات (فيديو، PDF، صور، برامج، مستندات...)
- سحب وإفلات (Drag & Drop)
- حفظ محلي كامل باستخدام IndexedDB
- بحث + ترتيب + عرض شبكة أو قائمة
- تصميم أقرب ما يكون لواجهة PS5: أزرق سوني، كروت ميديا، توهجات، عمق بصري

## طريقة التشغيل

1. افتح ملف `index.html` في المتصفح
2. ابدأ برفع ملفاتك وتنظيمها

## الملفات

كل الملفات في مستوى واحد بدون فولدرات لسهولة الرفع على GitHub.

## ملاحظات

- البيانات تُحفظ محلياً على جهازك فقط
- الحد الأقصى المقترح لكل ملف: 50 ميجابايت
- لا يحتاج إنترنت بعد أول فتح
